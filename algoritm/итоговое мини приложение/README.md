# Магазины рядом после 21:00

Приложение ищет ближайшие магазины с открытыми часами работы после 21:00 через OpenStreetMap Overpass API.

## Запуск

1. Перейдите в папку:
   ```powershell
   cd "c:\Users\VadoooS_S\Documents\уник1курс\algoritm\итоговое мини приложение"
   ```
2. Установите зависимости:
   ```powershell
   python -m pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```powershell
   python main.py
   ```
4. Откройте в браузере: `http://127.0.0.1:5000`
